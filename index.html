Selected work

Systems research · final-year project, rebuilt

DPI Guard: blocking a domain before its first connection completes

Deep packet inspection (nDPI) identifies which domain each connection goes to, and an eBPF/XDP program drops blocked traffic in the kernel driver, before the network stack sees it. Measuring the pipeline showed the bottleneck was neither DPI nor the kernel but packet-capture buffering. A filtered fast path for TLS ClientHellos removed it.

A speech-to-speech agent on a real phone number. It streams audio between Twilio and the OpenAI Realtime API, lets callers interrupt mid-sentence, and runs tool calls (order tracking, a cart, document search) concurrently without stalling the audio. Speaks English and Urdu.

UrduCap: image captioning in Urdu

Revisiting my 2024 model, I found its BLEU score was inflated by train/test leakage (99.8% of test images seen in training) and character-level scoring. Version 2 fixes the protocol and compares a CNN-GRU, SigLIP 2 + mBART-50, and a LoRA-tuned Qwen3-VL.
